# prompt.v44 迭代与实局验证

本文保留v44当时的验证结果，不表示当前默认版本或后端加载状态。现行方法见[迭代规范](prompt-iteration-guide.md)，版本状态和后续结论见[迭代台账](prompt-iteration-log.md)。

## 结论

`prompt.v44` 已完成一局七人真实模型验证。坏人不再全程跟票：第三轮否掉全好车后，重新推动含莫甘娜4号的车队，并由4号出失败阻止好人的第三次成功。刺客将真正梅林6号从此前同身份测试的第五位提高到第二位，但最终仍刺3号忠臣。终局为好人任务三胜、一败，刺杀未命中，好人获胜。

本次观察支持“坏人的任务目标更明确、刺杀时将6号保留为强候选”，不支持“刺杀已稳定准确”或“发言重复已解决”。

## 改动范围

- 行动目标改为先按真实阵营决定希望车队通过还是被否，再形成公开说法，避免先跟随好人表态、再为了保持一致放弃坏人目标。
- 组队、投票明确区分好人的安全目标和坏人的破坏目标；隐藏身份、保持票向与未知奥伯伦可能在车上，不再是连续放行好人赛点车的充分理由。
- 坏人可争车、换人或否决，也可在有具体目标证据或否决无益时进入刺杀，不强制每车反对。
- 刺客、莫甘娜和奥伯伦的策略同步围绕可控破坏点展开，不用纯粹低调代替阵营收益。
- 刺杀比较全部合法目标，保留车外低调跟随者；取消必须排除固定人数的要求，不为凑排除理由给他人硬分配身份。

只修改提示词正文、版本和说明，未改游戏规则、玩家合法信息边界、上下文结构或 JSON 输出契约。已有未提交修改均保留。

## 主要观察

### 坏人的反对有明确任务目的

第三轮第一案为全好车1、2、3。4、5、7均在发言时表达反对，随后投反对，没有先公开支持再无依据翻票。4、7的决策摘要明确指出当前车缺少可控破坏点，否决后希望由4号带队，把已知同伴放回任务；5号也以争取后续车位和阻拦第三次成功为目标。

该案最终被1、2、4、5、7否掉，原始数据库投票结果为 `#110`。不能说是三张坏人票独自决定结果：1、2两名好人也被“连续成功车不该无依据换人”的说法带动。

4号随后组回1、2、4，三名坏人转为赞成；4号在任务中出失败，原始任务结算为 `#146`。这是实际拿到一次任务失败，不只是发言上更主动。

第四轮，5号组出2、4、5、7，实际包含三名坏人且达到两失败门槛，4、5、7支持；该车被四名好人否掉。下一案为全好车1、2、3、6，三名坏人转为反对，四名好人赞成通过。此时坏人行为仍在争取任务破坏，而非继续被动放行。

奥伯伦5号不互认同伴；其与4、7同票不代表知道对方身份或事先配合。

### 刺杀没有再过早排除梅林，但仍选错

`v43` 同种子测试的刺杀排序为：

```text
3、2、1、5、6、4
```

本次 `v44` 为：

```text
3、6、1、2、5、4
```

刺客明确承认6号也很像梅林。不过他更看重3号较早反对4号、主动排除4号、提出重建车队，认为6号更像跟随3号框架的好人或派西维尔，因此仍刺3号。

3号提出换自己有其忠臣自知好人的依据；6号也确实顺着合理公开方案支持。如何比较这种主动忠臣与低调梅林，仍不能只凭发言先后或谁先提出骨架下结论。本次只观察到6号排位上升，未验证刺杀命中改善。6号第四轮也参加了成功任务，因此这局还不能单独证明“遗漏全程车外候选”的问题已解决。

### 成功车偏信和重复表达仍存在

1、2在第二轮成功后，倾向把4号当成更应保留的成功成员。第三轮1、2共同否掉1、2、3，再支持1、2、4，给4号创造了破坏机会。发言虽然常补充“成功不能验人”，实际决策仍明显受既有成功组合影响。

部分派西维尔判断仍重视“谁把风险说得更具体”：2号第二轮选4，主要理由是4首轮明确谈到失败门槛和成功不能验人。这些规则复述不应单独成为辨别梅林候选的强证据。

本局42条发言平均93.9字符，不超过50字符的只有3条；“样本、交叉、对照”仍未出现，但多人反复使用“连续性、没有公开依据排除、先推进看结果”等说法。较上一局局势更复杂、轮次更多，长度上升不能单独归因于提示词退步；重复本身仍是未解决的问题。
